# 原神杀 · 联机桌游

基于《三国杀》玩法基底、融入《原神》特性（元素、角色技能、提瓦特世界观）的可联机网页桌游。

- 纯 HTML + Node.js 实现，手机、电脑浏览器打开同一地址即可互通对战
- 无需安装任何客户端，只需 Node.js 环境
- 数据驱动设计：角色、卡牌、身份均为注册表式配置，后续可直接扩展正式原神角色/卡牌
- 当前版本：**v0.1 测试版**

---

## 一、快速开始

### 1. 环境要求（必装）

- **Node.js 16.0 或更高版本**：去官网下载安装 https://nodejs.org/ ，选LTS版本，一路下一步即可
- 浏览器用Chrome/Edge都行，不需要其他软件

### 2. 下载代码

**方式一：Git克隆（推荐）**
```bash
git clone https://github.com/momomomo678/Genshin-Impact-kill.git
cd Genshin-Impact-kill
```

**方式二：直接下载ZIP**
1. 打开 https://github.com/momomomo678/Genshin-Impact-kill
2. 点击绿色的 `Code` 按钮 → `Download ZIP`
3. 解压到任意文件夹

### 3. 安装依赖（⚠️ 首次必做，不做会报错！）

**如果双击启动游戏报错 "Cannot find module 'ws'"，就是因为没做这一步！**

在解压后的文件夹里打开命令行（在文件夹地址栏输入 `cmd` 回车），执行：
```bash
npm install
```
等待安装完成（大概1分钟），只需要装一次，以后不用再装。

### 4. 启动游戏

**方式一：一键启动（推荐）**
- 双击 `启动游戏.bat`，会自动启动服务器并打开浏览器

**方式二：手动启动**
```bash
node server.js
```

启动成功后终端会显示：
```
本机访问：   http://localhost:3000
局域网访问：http://192.168.x.x:3000
```

### 5. 开始游戏

- 电脑/手机浏览器打开上面的地址
- 输入昵称 → **创建房间**（房主）→ 等待好友加入；或点击 **补位 AI** 单人试玩
- 好友在手机/电脑浏览器打开同一地址 → 输入昵称 → 输入 4 位房间号 → **加入房间**
- 人齐后房主点击 **开始游戏**
- 支持 2~8 人，4 人局为 1 神明 / 1 护卫 / 1 魔物 / 1 深渊教团

> **重要：只有房主需要启动服务器！其他玩家不需要下载代码、不需要装Node.js，直接打开房主给的网页地址就能玩！**
>
> 房间解散后房间号即失效，需重新建房。

## 二、联机方式

### 方式一：局域网（同一 Wi-Fi / 路由器下）

手机与电脑连接同一网络，手机浏览器直接打开电脑终端显示的 **局域网地址**（如 `http://192.168.31.121:3000`）即可。

> 若打不开，请检查 Windows 防火墙是否放行 Node.js：设置 → 防火墙 → 允许应用通过 → 添加 Node.js（专用+公用）。

### 方式二：Cloudflared 临时隧道（外网联机，推荐）

适合不在同一WiFi下的朋友联机，免费且无需注册：

1. 下载安装 cloudflared：
   ```bash
   winget install --id Cloudflare.cloudflared
   ```
2. 启动游戏服务器后，新开一个命令行窗口，运行：
   ```bash
   cloudflared tunnel --url http://localhost:3000
   ```
3. 等待几秒，会输出一个 `https://xxx.trycloudflare.com` 的网址
4. 把这个网址发给朋友，他们直接在浏览器打开就能加入游戏

**注意**：临时隧道地址每次重启都会变，关掉命令行窗口隧道就失效了。

### 方式三：樱花映射（Sakura Frp，免费）

1. 注册/登录 [樱花映射官网](https://www.natfrp.com) 并实名认证
2. 下载对应系统（Windows）的启动器并运行
3. 在官网"隧道列表"点击 **创建隧道**：
   - 隧道类型：**TCP**
   - 本地端口：`3000`
   - 远程端口：自动分配（或自选，需有权限）
4. 复制生成的 **访问地址**（形如 `na2.natfrp.com:12345` 或 `xxxxx.cloud:12345`）
5. 把地址发给好友：手机/电脑浏览器打开 `http://访问地址` 即可加入

> 免费隧道地址会变化，每次启动前在官网复制最新地址即可。

## 三、游戏内容

### 身份与胜负

| 身份 | 目标 |
| --- | --- |
| 神明（主公） | 带领护卫消灭所有魔物与深渊教团 |
| 护卫（忠臣） | 保护神明，协助消灭魔物与深渊教团 |
| 魔物（反贼） | 击杀神明获胜 |
| 深渊教团（内奸） | 最后存活获胜 |

- 身份只在开局时私密发给本人，牌桌上**仅神明身份公开**
- 神明阵亡：若场上仅剩深渊教团，深渊教团胜；否则魔物胜
- 魔物与深渊教团全部阵亡：神明阵营胜

### 装备栏系统

每个玩家有4个装备栏：
- **武器栏**：默认最多装1件，空/荧因【双子】技能可装2件
- **防具栏**：默认最多装1件，空/荧可装2件
- **+1道具栏**：默认最多装1件，空/荧可装2件
- **-1道具栏**：默认最多装1件，空/荧可装2件

## 四、功能说明

### 主界面功能

- **创建房间**：创建新的联机房间
- **加入房间**：输入4位房间号加入好友的房间
- **测试模式**：单人调试模式，无身份系统，人偶不自动行动，房主可操作所有人偶，作弊面板可任意添加卡牌
- **设置**：音量调节、UI比例调节（局内外都可使用）
- **图鉴**：查看所有角色、手牌、身份的详细说明
- **公告**：查看游戏公告

### 游戏内功能

- **背景音乐**：主界面固定播放《柔风的欢愿》循环；游戏内随机播放5首背景音乐，播放结束自动切换下一首
- **音效**：选中牌和出牌都有对应音效
- **角色弹窗**：点击角色卡片可查看技能、装备、身上效果三个标签页
- **延时锦囊显示**：角色卡片上会显示被施加的延时锦囊牌
- **座位自适应**：座位以自己为中心排列，不会出现在上面

## 五、自定义修改指南

### 修改公告内容

编辑 `public/index.html` 中 `announcement-body` 部分的文字即可。

### 修改背景音乐

1. 把mp3文件放到 `public/music/` 文件夹
2. 编辑 `public/js/app.js` 中的 `gameBgmList` 数组，添加文件名
3. 主界面音乐是固定的，游戏内音乐会随机播放列表中的歌曲

### 添加角色

编辑 `src/characters.js`，在 `CHARACTERS` 注册表中新增一条：
```js
'琴': {
  name: '琴',
  element: '风',          // 元素：风/火/水/雷/草/冰/岩
  maxHp: 4,
  skills: [
    {
      name: '蒲公英之风',
      desc: '每回合限一次，你可以……',
      hooks: {},
    }
  ],
},
```

### 添加卡牌

编辑 `src/cards.js`：
1. 在 `CARD_META` 注册卡牌元信息
2. 在 `DECK` 中加入若干张
3. 在 `src/game.js` 的 `playCard` 效果分支中实现效果逻辑

### 修改游戏规则

编辑 `src/config.js` 中的配置项，如攻击次数限制、体力值等。

## 常见问题

| 问题 | 解决 |
| --- | --- |
| 局域网手机打不开 | 检查防火墙放行 Node.js；确认手机与电脑同网 |
| 房间号无效 | 房间已解散/过期，请房主重新建房 |
| 显示"连接已断开" | 网络波动或服务器停止，刷新页面重进 |
| 卡牌不出牌 | 确认是你的回合、出牌阶段、目标在攻击距离内 |
| 端口被占用 | 关闭其他占用3000端口的程序，或修改启动端口 |
| 外网联机显示不安全 | Cloudflared隧道是临时地址，点击"高级"→"继续访问"即可 |
